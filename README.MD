# ☁️ AWS Cloud Architecture & Operations Documentation

Welcome to my personal AWS documentation repository! Here you will find detailed guides, hands-on lab notes, CLI automations, and architectural breakdowns covering core Amazon Web Services based on practical re/Start labs and enterprise scenarios.

## 📁 Repository Structure

- **[Compute](./compute/)**: Amazon EC2, AWS CLI, Systems Manager (SSM), and AWS Lambda (Serverless computing).
- **[Networking](./networking/)**: VPC configuration, NAT Gateways, Elastic Load Balancing (ELB), Auto Scaling, and Route 53 (Failover & Health Checks).
- **[Database](./database/)**: Amazon RDS (Multi-AZ deployments and data migration from EC2/LAMP).
- **[Storage](./storage/)**: Amazon S3 (Static hosting, versioning, event notifications) and Amazon EBS (Volumes, snapshots, and automation).
- **[Management & Security](./management-security/)**: IAM policies, CloudWatch (Logs, Metrics, Alarms), AWS Config, CloudTrail forensics, and CloudFormation (Infrastructure as Code).

## 🚀 Projects Overview
This repository compiles multi-service architectural labs focused on high availability, security hardening (least privilege), fault tolerance, and automation.
